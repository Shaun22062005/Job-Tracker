# 💼 Job Tracker — Frontend Application

This directory contains the Angular 19 frontend for the **Job Tracker** portfolio application.

For complete project documentation, full-stack architecture details, backend setup, and feature highlights, please see the primary [Root README.md](../README.md).

## Development Commands

```bash
# Start dev server
npx ng serve --port 4200

# Build production bundle
npm run build

# Run unit tests
ng test
```
